2. Umfang der Datenverarbeitung

Die App arbeitet beim Lernen und Prüfen vollständig offline. Eine Datenübertragung findet ausschließlich beim einmaligen Einlösen eines Freischalt-Codes statt (siehe Ziffer 5).

  • Kein Tracking, keine Analyse-Tools, keine Werbe-IDs
  • Kein Nutzerkonto, keine Registrierung
  • Lernfortschritt und Prüfungsergebnisse werden ausschließlich lokal auf Ihrem Gerät gespeichert
  • Keine Weitergabe von Daten zu Werbe- oder Analysezwecken

3. Lokale Datenspeicherung

Folgende Daten werden ausschließlich lokal auf Ihrem Gerät gespeichert und verlassen dieses niemals:

  • Lernfortschritt (welche Fragen beantwortet, wie oft richtig/falsch)
  • Prüfungsergebnisse
  • Einstellungen (Suchhundtyp, Lizenzstatus)

Die optionale Backup-Funktion (Export / Import) erzeugt eine JSON-Datei auf Ihrem Gerät. Diese Datei enthält nur die oben genannten Lerndaten und liegt vollständig in Ihrer Kontrolle.

4. In-App-Käufe (Android)

Auf Android wird Google Play Billing für den einmaligen Freischaltungskauf genutzt. Die Zahlungsabwicklung erfolgt ausschließlich über Google. Die App erhält dabei keine Zahlungsdaten; der Freischaltstatus wird von Google Play bestätigt. Bitte beachten Sie die Datenschutzerklärung von Google.

5. Freischalt-Codes (Server-Prüfung)

Die Vollversion kann per Freischalt-Code aktiviert werden. Damit ein Code nur einmal verwendet werden kann, wird er beim Einlösen einmalig an einen Server geprüft. Dabei werden übertragen und gespeichert:

  • der eingegebene Freischalt-Code
  • eine zufällig erzeugte Geräte-Kennung (UUID) – ohne Bezug zu Ihrer Person, Ihrem Gerätemodell oder anderen Kennungen
  • der Zeitpunkt der Aktivierung

Zusätzlich verarbeitet der Server technisch bedingt kurzzeitig Ihre IP-Adresse. Ein Nutzerprofil wird nicht gebildet; die Daten werden ausschließlich dazu genutzt, die Mehrfachverwendung eines Codes zu verhindern.
